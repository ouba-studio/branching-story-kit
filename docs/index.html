branching-story-kit

A zero-dependency, native-ESM story engine for interactive fiction, visual novels, and romance story apps: relationship-state tracking, gated choices, a persistent memory log, save/restore, a static validator, and a JSON Schema. The demo on this page is not a mock-up — it runs on the published engine.

Powered by the real engine

This page imports StoryEngine from the package and plays examples/midnight-bookshop.mjs as a plain JSON manifest — no framework, no build step.

import { StoryEngine, validateStory } from "@ouba-studio/branching-story-kit";
import { story } from "./examples/midnight-bookshop.mjs";

validateStory(story);              // { valid: true, errors: [] }
const engine = new StoryEngine(story);
engine.remember("Reader chose the archive route");  // memory log
engine.choose(0);                  // applies effects, advances scene
engine.exportSave();               // JSON: state + history + memory

What the demo exercises

  • Gated choices — the letter ending only appears when trust ≥ 4.
  • State interpolation — scene 3 writes your {{item}} into the prose.
  • Free-text steering — your own line is stored with set(), logged with remember(), and jumps to Ending C.
  • External links — ending choices use href; the engine never navigates for you.
